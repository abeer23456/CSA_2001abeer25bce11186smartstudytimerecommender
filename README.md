# 📚 Smart Study Time Recommender

## 🔍 Overview

This project is an AI-based system that recommends how many hours a student should study for a subject based on difficulty, preparation level, importance, and exam proximity.

---

## 🎯 Objective

To help students plan their study time efficiently using basic AI and machine learning concepts.

---

## 🧠 AI Concepts Used

- Rule-based decision system
- Supervised learning (Decision Tree Regressor)
- Feature-based prediction

---

## ⚙️ How It Works

### Inputs:

- Difficulty (1–5)
- Days Left
- Preparation Level (1–5)
- Importance (1–5)

### Output:

- Recommended study hours
